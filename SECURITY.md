# Security Policy

## Supported versions

Security fixes are applied to the latest code on each repository's default branch.

## Reporting a vulnerability

Use the repository's **Security** tab and choose **Report a vulnerability** for a private report. Do not disclose suspected vulnerabilities in a public issue.

Include the affected area, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

If private reporting is unavailable, contact the owner through the GitHub profile contact method.
